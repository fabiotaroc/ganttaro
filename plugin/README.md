# Ganttaro plugin

The plugin bundles the [Ganttaro skill](skills/ganttaro/SKILL.md) and a connection
to the hosted MCP server for Codex, ChatGPT Work on desktop, Claude Code, and Cursor.

**[Install Ganttaro →](../README.md#setup-prompt)** — choose the setup prompt for
Codex / ChatGPT Work or Claude Code, or follow the Cursor instructions in the root README.
